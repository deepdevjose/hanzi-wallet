# 3,500 characters and avatar economy (development branch)

- **Official catalog**: `src/common-3500.json` contains exactly 3,500 unique Tier 1 common Chinese characters from the PRC's 2013 *Table of General Standard Chinese Characters* (通用规范汉字表). Source transcription: https://github.com/shengdoushi/common-standard-chinese-characters-table/blob/master/level-1.txt . Official announcement: https://www.moe.gov.cn/jyb_xwfb/s5147/201308/t20130828_156388.html .
- **HSK classification**: `src/hsk-all.json` maps 3,011 of those characters to syllabus levels from https://github.com/profesorm/hsk30 (2026 edition). The remaining 489 are marked unclassified: this is not an error, because the national standard and HSK are different datasets. This is an independent mapping, and must not be confused with the application's previous 500-character subset.
- **Existing handwriting model**: the model and detailed flashcards still support 500 characters. Other common characters can be browsed, but cannot yet be written/recognized, and are visually disabled. Do not claim 3,500-character writing recognition until new aligned geometric data, dictionary glosses, pronunciation, translations, model weights and tests are built.
- **Profile, avatar and shop**: `src/profile.ts` creates local onboarding, appearance selection and coin-based items. The current avatar artwork uses provisional emoji compositions; production-grade stylized Chinese cartoon characters require new assets and responsive equipment layers. Coins are tied to new XP earned after this feature is first loaded, to avoid awarding an unbounded retroactive balance. Levels follow existing `XP_PER_LEVEL=100`.
- **Storage/security**: `hanzi-wallet-avatar-v1` is local browser storage. There is no backend, purchases or authoritative balance validation. The economy is educational, not tamper-proof. Avatar profiles now travel in the existing JSON export/import format under `avatarProfile`; legacy backups without this field remain valid.
- **QA**: run `npm ci && npm run typecheck && npm test && npm run build`, verify mobile navigation, first-run dialog, returning-user state, storage-disabled behavior, coin earn-once, shopping, level 400 lock, and the 3,500 search/filter. No runtime test result is claimed until CI confirms.

## Known source limitation

The open-source Make Me a Hanzi dictionary (https://github.com/skishore/makemeahanzi) covers over 9,000 glyphs and publishes pinyin, English learner definitions, and decomposition, while its graphics carry Arphic terms. The dictionary has a separate licence path and must be processed with attribution and version pinning before shipping a complete multilingual catalogue. Do not silently translate missing French, Portuguese or Spanish definitions from English without a verified translation workflow.

## User experience follow-up

The catalog currently has full word entries for the 500 legacy characters only. Remaining characters are present and classified by HSK where possible, but do not masquerade as tested recall exercises. Next milestone: compile static local files from a pinned dictionary snapshot and separate handwriting templates from the 500-class recognition model.
